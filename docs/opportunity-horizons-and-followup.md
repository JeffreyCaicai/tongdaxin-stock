# 推荐周期与后续表现口径

## 版本边界

- 原版推荐排序：`market_opportunities_v1`，仍固定20交易日，筛选门槛和入选标准未调整。
- 分周期技术判断：`technical_horizons_v1`，新增到扫描时保存的 `period_assessments`，不影响原版名单。
- 表现观察：`opportunity_followup_v1`，单独保存到 `opportunity_followups`。旧报告缺失周期判断时标记 `legacy`，不使用后来的数据补算历史判断。

## 周期规则

|观察期|快/慢均线|慢均线斜率回看|最低日线数|偏离门槛|
|---|---|---|---|---|
|5日|MA5 / MA20|5日|30|高于MA20超过8%|
|20日|MA20 / MA60|5日|65|高于MA20超过15%|
|60日|MA60 / MA120|10日|130|高于MA60超过25%|
|120日|MA60 / MA180|20日|200|高于MA60超过35%|

所有输入使用上海时间下已收盘的日线。个股必须覆盖对应指数窗口的全部日期；缺日、重复日、无效OHLC、零或缺成交量、末日不一致、超过10自然日未更新时不计算有效周期分。10日时效门槛是保守规则，不是交易日历服务；长假、停牌和接口缺失仍需核查。

技术检查从50分起：

- 趋势组：价格 > 快均线 > 慢均线且慢均线上行，+25；价格低于快均线，-25；其余0。
- 相对强弱组：同一N日窗口跑赢沪深300，+15；跑输-15；持平0。绝对动量只展示，不重复加分。
- 成交量组：最近成交量/20日均量 >= 0.8，+5；否则-5。
- 风险组：ATR14/收盘价 > 6%，-15；超过上述均线偏离门槛，另-15。

总分限制在0至100。>=75且趋势与相对强弱均为正时，列为“条件较有利”；<45为“暂不支持参与”；其余为“等待确认”。过度偏离、下降趋势、高波动压力或未知大盘状态将“条件较有利”降为“等待确认”。这些是手工阈值，不是已经优化验证的概率模型。价格参考是快均线和快均线减ATR14，均为复核触发参考，不是下单指令。

长期价值判断需要财务、现金流、估值、行业及事件数据；当前未接入完整验证链，始终显示证据不足。现有候选发现仍是有限条件选股样本，偏向已有趋势；多周期展示不等于全市场长期价值选股。

## 后续观察

推荐生成时间转换到上海日期；不使用当天可能早于信号的价格作为起点。取严格晚于该日期的第一根沪深300日线为第1交易日，以同日股票开盘为参考。第N根指数日线对应股票收盘为终点。

- 价格涨跌 = 期末收盘 / 参考开盘 - 1。
- 超额 = 股票价格涨跌 - 指数同期涨跌，单位为百分点，不是回归alpha。
- 回撤 = 从参考开盘及后续各日收盘路径中计算的最深跌幅，不是盘中低点回撤。
- 未到期不计入收益统计；已到期但缺股票交易日、成交量或价格则不可评估，不能伪装为0。
- 未到期也先检查推荐日后已经收盘的观察数据：只要已观察交易日缺失、OHLC无效、日期重复或成交量为零/缺失，
  即标记不可评估，价格和收益指标保留null；数据完整且尚不足N日时才显示未到期。尚无推荐日后的已收盘交易日时
  正常等待，不要求未来价格。未到期检查排除日期明确且不晚于推荐日的个股历史异常；无法确定日期的异常仍阻断评估。
- 原版入选/未入选/排除组分别统计；同一周期的原始 favorable/wait/avoid/insufficient/legacy 组也分别统计。

跟踪使用同源同批复权口径日线的两端价格，避免拿原实时价与后来复权价混算。每次刷新可更新观察值，但不改动原始推荐内容。官方接口仅拉取最近1000根日线，超出覆盖范围明确标记。指标不承诺真实成交收益；未完成独立样本验证前，不声称准确度已经提升。

刷新排队、运行、失败、取消或服务中断时，如已有保存结果，界面会明确提示正在显示上次结果，保留其行情截止日和
结果评估时间。尝试刷新的时间不代表行情已更新。选择的5/20/60/120日窗口在同一记录的轮询、重连、手动刷新和
语言切换期间保持；打开另一条记录默认20日。读取或重新连接记录仍是只读操作，只有“更新表现”启动行情任务。

## 验证与后续方向

单元测试覆盖时区、未收盘与未来数据排除、缺失数据、日期对齐、周期差异、过度偏离、旧报告保护、任务取消与恢复。浏览器测试检查中英文、请求竞争和移动端。

积累真实成熟样本后再做按时间分段的训练外验证；隔离重叠标签窗口和同股票重复记录，再评估阈值、行业分组、交易成本及概率校准。当前分组均值不能替代这一步。
