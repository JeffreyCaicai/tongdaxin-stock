# 缠论结构与行情概况

## 缠论结构

模型 `daily_pen_overlap_v2` 是**日线笔级近似**，不是严格的递归缠论系统，也不是自动交易信号。三笔重叠区不能直接等同于三个次级别走势构成的中枢。原作者对级别和次级别确认的说明见[《教你炒股票53》](https://blog.sina.com.cn/s/blog_486e105c01000aqw.html)。

- 只接受日线。按上海时间15:00划分完成日，不把当日盘中日线或未来数据用于结构判断。
- 验证 OHLC 为有限正数及高低关系，按日期去重排序。无效、重复、少于35根或距今超过10个自然日的数据会暂停候选判断。没有交易所假期日历，长假边界需要人工复核。
- 合并包含K线时保留实际高低点日期；分型包含右侧确认日期。末端笔可能延伸，图中用虚线，排除在中枢和候选计算之外。这里的“稳定”只表示当前快照中已有后续相反拐点，不保证供应商历史修订后不变。
- 中枢来自稳定笔的严格正宽度重叠；不合并时间上分离的重叠区。笔区间高低点包括内部日线影线，而不只看两个端点。
- 三买/三卖仍是候选。要求中枢形成后的离开及稳定回试，回试全过程高低范围位于边界外，不能只凭最后一笔方向判断。触及边界即不满足本模型的保守候选条件。没有次级别验证，不标为确认买卖点。
- 离旧中枢太远时只作历史参考。最近稳定笔超过20根日线没有更新时，等待新结构，不沿用老候选。
- 页面价格明确标为“结构收盘价”，附日线截止日，不能与盘中报价混用。图最多显示160根已收盘日线；窗口之外的笔不绘制，完整统计仍来自本次可用输入。
- 复权口径未跨供应商统一验证。除权、分红和历史数据修订可能改变结构；尚未实现线段递归、次级别验证、背驰验证、样本外胜率验证。

本次共享缠论证据变更后，决策引擎版本为 `rule_based_scenario_v2`，机会筛选版本为 `market_opportunities_v2`。原有历史报告、推荐名单和后验跟踪保留原版本，不回填“当时已知”的结果。周期评价模型本身未改。

## 行情概况

`pool_quote_snapshot_v2` 提供现价、相对昨收涨跌幅、成交额、换手率、开高低价、读取时间和质量状态。不调用原有止盈止损行动逻辑。

- 有效价格不能是空值、布尔值、非有限数或非正数；错误股票代码的报价不使用。
- 同时提供现价与昨收时重新计算涨跌幅；与供应商字段显著不一致时显示重算标记。
- 有效报价覆盖率的分母是本次扫描股票数。涨跌分布和等权平均只包含读取时间可核实、24小时内且涨跌幅有效的报价；其他记为未知，不按0%计入。
- 该分布是**本股票池报价的横截面**，并非全市场宽度，且不保证各股票最后一笔成交日期相同。不能单独据此判定大盘状态。
- `fetched_at` 是读取时间，不是交易所行情时间。未取得交易所时间时明确显示未提供；成功读取不等于实时成交、当日成交或可交易状态。
- 官方源解析 `MaxP / MinP` 和 `HQDate / HQTime`，行情时间标为上海时区。已知行情日期超过10个自然日或在未来时排除出涨跌分布，不能因再次读取就视为新行情。
- 列表可按涨跌筛选、按涨跌幅或成交额排序。空值永远排在末尾。持仓成本和数量不因运行分析而变动。
- 历史报告缺少图形、时间或质量元数据时保留原样并标记，需要重新分析才能得到新字段。
- 上游服务异常、限流、权限失败和本地 Token 缺失使用独立原因分类；界面与报告不回显上游原始错误正文或凭证。
